# В потоке · Медхат Даиров

Лендинг тренера по плаванию в Астане. Адаптивный сайт на HTML, CSS и JavaScript, без базы данных и внешних зависимостей сборки. Фото тренера обработано из предоставленного изображения.

## Запуск

Требуется Node.js 20 или новее. Устанавливать пакеты не нужно.

```sh
npm run dev
```

Откройте `http://localhost:4173`. Для сборки выполните `npm run build`; папка `dist` готова для статического хостинга. `npm run preview` показывает собранный сайт. `npm test` проверяет расписание, API и Apps Script с имитацией Google/Telegram, без реальных отправок.

## Запись и редактирование

- Пока Google API не подключён, форма собирает выбранную группу и контакты в готовое сообщение WhatsApp. Посетитель отправляет сообщение сам. Сайт не показывает ложное подтверждение отправки.
- После подключения Google Apps Script расписание и основные тексты загружаются из Google Таблицы; заявки сохраняются в закрытый лист и отправляются в Telegram тренера.
- Группы «Мастер» видны в расписании, но закрыты для публичной записи, включая проверку на сервере.
- Изменения таблицы видны после обновления страницы. Аккаунты посетителей и отдельная база данных не нужны.

Подробная установка: [docs/INTEGRATION.md](docs/INTEGRATION.md). Нужен URL веб-приложения Apps Script в `public/site-config.json`. Токен Telegram-бота и chat ID сохраняются **только в свойствах Apps Script**, не на сайте.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html`, `src/styles.css` | Страница и адаптивный дизайн |
| `src/main.js` | Расписание, формы, доступная навигация |
| `src/data.js` | Исходное расписание и тексты |
| `src/api.js` | Клиент Google Apps Script |
| `public/site-config.json` | Публичный URL API |
| `google-apps-script/Code.gs` | Google Таблицы, валидация, Telegram |
| `public/images/ASSETS.md` | Происхождение и обработка изображений |

Точный адрес бассейна и стоимость не предоставлены; сайт предлагает уточнить их у тренера. Контакт: +7 707 620 4904. Бренд «В потоке» предложен для этого дизайна и меняется в таблице.
