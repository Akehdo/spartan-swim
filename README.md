# SPARTAN SWIM

Сайт школы плавания в Астане: Медхат Даиров — старший тренер, Эрик Раскулов, Константин Романенко и Андрей Беляков — команда тренеров. Адаптивный сайт на HTML, CSS и JavaScript, без отдельной базы данных и внешних зависимостей сборки. Использованы предоставленные фотографии.

## Запуск

Требуется Node.js 20 или новее. Устанавливать пакеты не нужно.

```sh
npm run dev
```

Откройте `http://127.0.0.1:4173/`. Для сборки выполните `npm run build`; папка `dist` готова для статического хостинга. `npm run preview` показывает собранный сайт. `npm test` проверяет расписание, API и Apps Script с имитацией Google/Telegram, без реальных отправок.

## Запись и редактирование

- Пока Google API не подключён, форма собирает выбранную группу и контакты в готовое сообщение WhatsApp. Посетитель отправляет сообщение сам. Сайт не показывает ложное подтверждение отправки.
- После подключения Google Apps Script расписание, тренеры и основные тексты загружаются из Google Таблицы. Заявки сохраняются в закрытом листе «Заявки» вместе с выбранной группой, днями, временем и предпочтением по тренеру; уведомление поступает в Telegram менеджера.
- Группы «Мастер» видны в расписании, но закрыты для публичной записи, включая проверку на сервере.
- Медхат управляет листами «Настройки», «Расписание», «Тренеры» и обрабатывает заявки в своей таблице. Изменения видны после обновления сайта. Аккаунты посетителей не нужны.

Подробная установка: [docs/INTEGRATION.md](docs/INTEGRATION.md). Нужен URL веб-приложения Apps Script в `public/site-config.json`. Токен Telegram-бота и chat ID сохраняются **только в свойствах Apps Script**, не на сайте.

При обновлении существующей интеграции замените `Code.gs`, запустите `setup()` и обновите версию развертывания. `setup()` сохраняет заявки и правки менеджера, добавляет «Тренеры» и столбцы предпочтения по тренеру. Код в репозитории сам по себе не обновляет уже опубликованный Apps Script.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html`, `src/styles.css` | Страница и адаптивный дизайн |
| `src/main.js` | Расписание, формы, доступная навигация |
| `src/data.js` | Исходное расписание и тексты |
| `src/api.js` | Клиент Google Apps Script |
| `public/site-config.json` | Публичный URL API |
| `google-apps-script/Code.gs` | Google Таблицы, валидация, Telegram |
| `public/images/ASSETS.md` | Происхождение и обработка изображений |
