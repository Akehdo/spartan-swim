# Google Таблицы и Telegram

Сайт работает без отдельной базы данных. Расписание и публичные тексты читаются из Google Таблицы, заявки сохраняются в закрытый лист «Заявки». Google Apps Script отправляет уведомления тренеру в Telegram. Секреты остаются в Apps Script.

## 1. Подготовить таблицу

1. Создайте Google Таблицу в аккаунте тренера. **Не публикуйте таблицу в интернете**: заявки содержат телефоны и данные детей.
2. В таблице выберите **Расширения → Apps Script**.
3. Замените содержимое `Code.gs` кодом из `google-apps-script/Code.gs`.
4. В настройках проекта включите отображение файла манифеста `appsscript.json`; замените его содержимое файлом из `google-apps-script/appsscript.json`.
5. Сохраните проект. Выберите функцию **setup** и нажмите **Выполнить**. Подтвердите доступ своего скрипта к таблице, внешним запросам и триггерам.

`setup()` создаёт листы «Настройки», «Расписание», «Заявки», записывает исходное расписание и устанавливает повторную доставку уведомлений раз в 5 минут. Повторный запуск не стирает уже заполненные листы и добавляет только отсутствующие ключи настроек. `SPREADSHEET_ID` сохраняется автоматически.

## 2. Подключить Telegram

1. В Telegram откройте [@BotFather](https://t.me/BotFather), выполните `/newbot` и создайте бота. Сохраните выданный токен у себя.
2. Откройте созданного бота в аккаунте тренера и нажмите **Запустить / Start**. Бот сможет писать тренеру после этого действия.
3. Узнайте `chat.id` своего диалога через официальный метод Telegram [`getUpdates`](https://core.telegram.org/bots/api#getupdates). Выполните запрос к `https://api.telegram.org/bot<ТОКЕН>/getUpdates` локально, заменив `<ТОКЕН>` токеном бота, и найдите `result[].message.chat.id`. Если `result` пуст, отправьте боту сообщение и повторите запрос. Не пересылайте токен в чат и не добавляйте его в репозиторий.
4. В Apps Script откройте **Настройки проекта → Свойства скрипта → Добавить свойство**:

| Свойство | Значение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен от BotFather |
| `TELEGRAM_CHAT_ID` | Числовой ID диалога тренера |

Токен и ID не передаются на сайт. Отправка идёт из Apps Script через [`sendMessage`](https://core.telegram.org/bots/api#sendmessage). Telegram получает текст без режима HTML/Markdown, поэтому введённое посетителем имя не меняет формат сообщения.

## 3. Опубликовать API и подключить сайт

1. В Apps Script выберите **Развернуть → Новое развертывание → Веб-приложение**.
2. **Запускать от имени:** вашего аккаунта. **У кого есть доступ:** все, включая пользователей без входа в Google. Если организация запрещает анонимные веб-приложения, потребуется разрешённый аккаунт или отдельный серверный адаптер.
3. Нажмите **Развернуть** и скопируйте URL вида `https://script.google.com/macros/s/…/exec`. Используйте `/exec`, а не тестовый `/dev`.
4. Добавьте URL в `public/site-config.json` в поле `appsScriptUrl`: `{"appsScriptUrl":"https://script.google.com/macros/s/…/exec"}`. Это публичный адрес API, секретов в нём нет. После изменения пересоберите сайт.
5. Откройте `ВАШ_URL?action=bootstrap`: должен вернуться JSON с `ok: true`, публичными настройками и расписанием. Список заявок этот API не возвращает.
6. На сайте выберите обычную группу, заполните форму и отправьте **одну тестовую заявку с вашими данными**. Проверьте новую строку в «Заявках» и сообщение в Telegram. Удалите тестовую строку из таблицы, когда проверка завершена.

После изменения `Code.gs` нужно обновить развертывание через **Развернуть → Управление развертываниями → Изменить → Новая версия**. Правки данных в таблице обновления кода не требуют.

Браузер отправляет JSON как `text/plain;charset=utf-8` и следует перенаправлению Google. Не меняйте заголовок на `application/json`: это вызывает предварительный CORS-запрос, который Apps Script не обрабатывает. Не используйте `mode: 'no-cors'`: он скрывает ответ, и сайт не сможет подтвердить сохранение заявки. Если ответ не прочитан из-за сетевого сбоя, повторите заявку с тем же `requestId`: сервер не создаст дубликат.

## Что тренер может менять сам

В «Настройках» редактируйте только столбец `value`, названия ключей оставляйте прежними:

| Ключ | Содержимое |
| --- | --- |
| `brandName` | Название проекта |
| `coachName` | Имя тренера |
| `heroTitle` / `heroDescription` | Заголовок и описание первого экрана |
| `coachIntro` | Вступительный текст о тренере |
| `location` | Город, название бассейна и адрес |
| `phone` | Номер телефона в читаемом формате |
| `whatsapp` | Номер WhatsApp с кодом страны, только цифры |
| `instagram` | Ссылка на Instagram |
| `contactNote` | Дополнительная информация о связи |

Поля `childrenTitle`, `childrenDescription`, `adultsTitle`, `adultsDescription`, `childrenPrice`, `adultsPrice` от прежних карточек могут остаться в существующей таблице; в текущем компактном лендинге они не отображаются.

Пустые необязательные значения можно оставить пустыми. Телефоны, ссылки и тексты из этого листа публичны; не записывайте сюда токены или сведения о заявках.

В «Расписании» одна строка — одна группа, которая занимается несколько раз в неделю:

| Столбец | Формат |
| --- | --- |
| `id` | Уникальный постоянный ID латиницей, например `children-mwf-0800` |
| `audience` | `children` — дети, `adults` — взрослые |
| `days` | Дни через запятую: `mon,wed,fri` или `tue,thu,sat` |
| `start`, `end` | Часы в 24-часовом формате `08:00`, `09:00` |
| `level` | `all` — открытая запись, `master` — группа «Мастер», публичная запись закрыта |
| `active` | `TRUE` — активна, `FALSE` — временно закрыта |

Дни: `mon` ПН, `tue` ВТ, `wed` СР, `thu` ЧТ, `fri` ПТ, `sat` СБ, `sun` ВС. Заголовки и имена листов не переименовывайте. ID уже существующей группы сохраняйте, даже если меняете её часы. Некорректные строки не выдаются в API. Группы «Мастер» закрыты для публичной записи и в интерфейсе, и на сервере; сервер сверяется с актуальной таблицей при каждой заявке.

Исходное расписание:

| Участники | Дни | Начало занятий |
| --- | --- | --- |
| Дети | ПН СР ПТ | 08:00, 15:00, 19:00, 20:00 |
| Дети | ВТ ЧТ СБ | 08:00, 16:00, 19:00, 20:00 |
| Взрослые | ПН СР ПТ | 08:00, 12:00, 13:00 «Мастер», 19:00 «Мастер», 21:00 |
| Взрослые | ВТ ЧТ | 08:00, 12:00 |

Каждое занятие длится один час. Конкретный допустимый возраст и возможность участия тренер подтверждает при связи; поле возраста в форме лишь различает детские заявки.

## Заявки и доставка

В листе «Заявки» сохраняются дата, ID запроса, ID заявки, контакт взрослого, телефон, имя и возраст участника, уровень, группа, согласие и состояние уведомления. Это заявка на обратную связь: место в группе окончательно подтверждает тренер.

| `telegramStatus` | Значение |
| --- | --- |
| `pending` | Заявка сохранена, отправка ещё не завершилась |
| `sent` | Telegram подтвердил отправку |
| `error` | Telegram недоступен или отклонил запрос; будет повтор |
| `not_configured` | Не заполнен токен или ID диалога |

Сайт считает заявку принятой только после подтверждённой записи в таблицу. `notificationSent: false` означает, что уведомление ещё не доставлено; уже сохранённая заявка не теряется. Фоновый триггер повторяет до пяти попыток, максимум десять уведомлений за запуск. После исправления токена/ID можно вручную выполнить `retryFailedNotifications`. Если лимит пяти попыток исчерпан, исправьте причину и обнулите `telegramAttempts` для нужной строки. Повторная отправка после сетевого таймаута Telegram теоретически может продублировать уведомление: ориентируйтесь на ID заявки.

Сервер проверяет согласие, обязательные поля, телефон, существование и состояние группы; блокирует публичную запись в «Мастер». Повтор с тем же `requestId` возвращает уже сохранённую заявку. Параллельные записи защищены `LockService`. Значения, начинающиеся с `=`, `+`, `-`, `@`, экранируются перед записью в таблицу. Для простого ограничения спама используются скрытое поле и ограничение числа заявок с одного номера.

Доступ к самой таблице выдавайте только тренеру и тем, кто действительно обрабатывает заявки. Публикуется веб-приложение API, а не документ таблицы. Текст согласия на сайте должен соответствовать фактическим условиям обработки заявок владельцем сайта.

## Контракт API

`GET ?action=bootstrap`

```json
{
  "ok": true,
  "settings": {"brandName": "В потоке", "coachName": "Медхат Даиров"},
  "schedule": [{"id":"children-mwf-0800","audience":"children","days":["mon","wed","fri"],"start":"08:00","end":"09:00","level":"all","active":true}]
}
```

`POST`, тело JSON, `Content-Type: text/plain;charset=utf-8`:

```json
{
  "action":"register",
  "groupId":"children-mwf-0800",
  "name":"Имя родителя",
  "phone":"+7 700 000 0000",
  "participantName":"Имя ребёнка",
  "age":8,
  "experience":"beginner",
  "consent":true,
  "website":"",
  "requestId":"11111111-2222-4333-8444-555555555555"
}
```

Для взрослого участника `participantName` и `age` можно оставить пустыми. `experience`: `beginner` или `confident`. Успех: `{"ok":true,"registrationId":"…","notificationSent":true}`. Ошибка: `{"ok":false,"error":{"code":"…","message":"…"}}`. Apps Script возвращает прикладные ошибки в JSON; проверяйте `ok`, а не только HTTP-статус.

Официальные справочники: [веб-приложения Apps Script](https://developers.google.com/apps-script/guides/web), [Content Service и перенаправления](https://developers.google.com/apps-script/guides/content), [свойства скрипта](https://developers.google.com/apps-script/guides/properties), [LockService](https://developers.google.com/apps-script/reference/lock/lock-service), [UrlFetchApp](https://developers.google.com/apps-script/reference/url-fetch/url-fetch-app), [Telegram Bot API](https://core.telegram.org/bots/api).
